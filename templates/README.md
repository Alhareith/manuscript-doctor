# قوالب الواجهة

يحتوي هذا المجلد على قوالب Flask التي تُعرض للمستخدم. القالب الرئيسي هو `index.html`، ويحتوي هيكل مساحة العمل العربية RTL، ومراحل الرفع والتحليل والمعالجة، والمحرر اليدوي، والمقارنة، والسجل، والتنزيل.

## مسؤولية `index.html`

| المنطقة | الوظيفة |
| --- | --- |
| Header | الهوية البصرية وخلفية مساحة العمل |
| Workflow | توضيح مرحلة الرفع والتحليل والمعالجة والتحقق والإخراج |
| Dashboard | مؤشرات الصورة والتحليلات والرسوم |
| Manual Studio | اختيار العملية، المعاملات، Preview، ومخطط الأثر |
| Comparison | before/after المرتبطان بالخطوة النشطة |
| History | السلسلة اليدوية وUndo/Redo |
| Smart Pipeline | عرض القرار والنتيجة الذكية داخل مساحة العمل الموحدة |

القالب لا ينفذ عمليات OpenCV. يربط عناصر الواجهة بملفات JavaScript المقسمة، بينما تنفذ Flask وطبقة `processing` الاعتماد النهائي.

## قواعد التعديل

يجب الحفاظ على IDs وعقود API التي تعتمد عليها `static/js/parts/`. يوجد زر اعتماد واحد لإضافة العملية إلى السلسلة؛ لا تُضاف أزرار تنفيذ مكررة. عند تغيير بنية عنصر، راجع حالة الواجهة وbefore/after وCrop وSuper Resolution معاً.
