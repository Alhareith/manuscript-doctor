## المحتويات

## المسؤولية

يحوي HTML الذي يرسم الصفحة. لا يوضع فيه منطق معالجة الصور.

## الملفات

`index.html` سيكون صفحة مساحة العمل: رفع، تشخيص، أدوات معالجة، مقارنة، وتنزيل.

## الخطوة التالية

إنشاء بنية الصفحة قبل تنسيقها أو ربطها بالواجهة الخلفية.
