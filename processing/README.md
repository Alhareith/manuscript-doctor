## المسؤولية

## الملفات

| الملف | دوره لاحقًا |
| --- | --- |
| `analyzer.py` | قياس خصائص الصورة وبناء التشخيص. |
| `operations.py` | العمليات اليدوية المستقلة. |
| `pipeline.py` | ترتيب المعالجة الذكية وتفسيرها. |
