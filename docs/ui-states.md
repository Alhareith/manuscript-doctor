# UI States — Manuscript Doctor

يحدد هذا الملف جميع حالات واجهة المستخدم، والعناصر الظاهرة والمخفية في كل حالة، وسلوك النظام المتوقع.

---

## الحالات الأساسية

| الحالة | الوصف | العناصر الظاهرة | العناصر المخفية/المعطلة |
|--------|-------|-----------------|-------------------------|
| **State 1 — Empty** | لا صورة مرفوعة | Header, Upload Area (فعال) | جميع الأقسام الأخرى |
| **State 2 — Image Selected** | اختار صورة ولم يرفعها بعد | Header, Upload Area مع Preview, اسم الملف, زر "رفع وتحليل" | باقي الأقسام |
| **State 3 — Uploading/Analyzing** | جاري الرفع والتحليل | Header, رسالة "جاري رفع الصورة وتحليلها..." مع مؤشر, زر الرفع معطل | باقي الأقسام |
| **State 4 — Analysis Ready** | اكتمل التحليل | Header, Upload Area (يمكن إعادة الرفع), Image Overview, Diagnosis, Recommended Action, Smart Enhancement, Manual Tools | Comparison, Summary, Download |
| **State 5 — Processing** | جاري تطبيق معالجة | Header, رسالة "جاري تطبيق المعالجة...", تعطيل جميع أزرار التشغيل | - |
| **State 6 — Result Ready** | نتيجة المعالجة جاهزة | Header, جميع الأقسام بما فيها Comparison, Processing Summary, Download (فعال) | - |
| **State 7 — Error** | خطأ | Header, رسالة خطأ واضحة, زر لإعادة المحاولة أو اختيار صورة جديدة | باقي الأقسام |

---

## انتقالات الحالات

### State 1 → State 2
- المستخدم يسحب صورة أو يضغط "اختيار صورة".
- تظهر معاينة (Preview) محلية دون رفع الملف للخادم.
- اسم الملف يظهر بجانب المعاينة.

### State 2 → State 3
- المستخدم يضغط "رفع وتحليل الصورة".
- يُعطل الزر فورًا لمنع الطلبات المتكررة.
- يظهر مؤشر تحميل بسيط (نص + CSS spinner).
- لا يُسمح بأي تفاعل آخر حتى انتهاء الطلب.

### State 3 → State 4
- نجح الرفع والتحليل.
- تظهر الأقسام التالية: Image Overview, Diagnosis, Recommended Action, Smart Enhancement, Manual Tools.
- يمكن للمستخدم إعادة الرفع (Upload Area يبقى فعالًا).

### State 3 → State 7
- فشل الرفع أو التحليل.
- تظهر رسالة خطأ مناسبة (نوع ملف، حجم، تالف، إلخ).
- يمكن إعادة المحاولة.

### State 4 → State 5
- المستخدم يبدأ عملية معالجة (تلقائية أو يدوية).
- تُعطل جميع أزرار التشغيل.
- يظهر مؤشر "جاري تطبيق المعالجة...".

### State 5 → State 6
- نجحت المعالجة.
- تظهر الأقسام: Comparison, Processing Summary, Download (فعال).

### State 5 → State 7
- فشلت المعالجة.
- تظهر رسالة خطأ مناسبة.

### State 6 → State 5
- المستخدم يطبق معالجة جديدة على الصورة الأصلية.
- يُعاد إخفاء Download وتفعيله مجددًا بعد النتيجة الجديدة.

### State 6 → State 1
- المستخدم يرفع صورة جديدة.
- تعود الواجهة إلى State 1 ونفس الدورة.

## أنواع الأخطاء

| نوع الخطأ | الرسالة للمستخدم | متى يظهر |
|-----------|-----------------|----------|
| نوع ملف غير مدعوم | نوع الملف غير مدعوم. استخدم JPG أو JPEG أو PNG. | فشل التحقق من الامتداد |
| صورة تالفة | تعذر قراءة الصورة. جرّب اختيار صورة أخرى. | فشل فتح الصورة بـ OpenCV |
| حجم كبير | حجم الصورة يتجاوز الحد المسموح. | فشل التحقق من الحجم |
| خطأ معالجة | تعذر تنفيذ المعالجة على هذه الصورة. | فشل تنفيذ الفلتر |
| خطأ في الخادم | حدث خطأ غير متوقع. يرجى المحاولة لاحقًا. | أي خطأ غير متوقع |
