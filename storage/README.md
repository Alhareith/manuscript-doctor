## المسؤولية

هذا المجلد مخصص للملفات المؤقتة التي ينشئها التطبيق أثناء التشغيل.

## القواعد

- `uploads/`: الصور الأصلية المرفوعة.
- `results/`: النتائج القابلة للتنزيل.
- لا تُرفع محتويات هذين المجلدين إلى Git.
- مدة الاحتفاظ والحذف تحدد قبل نشر التطبيق.

## الخطوة التالية

إضافة سياسة حذف مؤقت عند تنفيذ الرفع والتنزيل.
